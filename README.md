# 蒋涛 · 个人作品集

React + Vite 单页作品集，独立位于本目录，没有覆盖上级原有网站。

当前方向：依据用户参考，整站使用浅薰衣草、淡粉灰、黑色 Epilogue 粗体和开放留白。首屏与页尾展示参考提供的角色视频，桌面视线随鼠标方位改变，手机正常静音播放；支持系统减少动态效果。

移动端首屏（700px 及以下）使用同一网格构图：姓名及专业信息在左上，简介标签在右上；英文标题放大为两行，第一行靠左、第二行靠右。中文简介及作品入口在左，角色在右，不再将视频单独堆在文案下方。角色左侧与底部柔和融入背景。手机个人肖像区域（650px 及以下）居中，保持原有尺寸；桌面布局、IP 作品栏目及开场动效不变。

## 启动

本地预览：http://127.0.0.1:5173/

Windows 可双击 `start-preview.cmd`。如果预览已运行，直接打开地址即可；不会结束已占用端口的其他进程。Node.js 22.12+ 环境也可使用：

```sh
npm ci
npm run dev
```

打包：`npm run build`，产物位于 `dist/`。
检查生产打包结果：`npm run preview`，地址 http://127.0.0.1:4173/ 。
网站保持本地，没有发布到公网。

## 动效

- 详情设计与首页设计的黑色拖动提示首次进入视野时播放一次下落回弹：按提示底部与右侧图片卡片上沿的实际距离落下，接触时横向舒展、纵向轻压，再弹起并衰减归位。动画约 1.65 秒，开始前缓冲 120ms，等待 jt 开场退场和图片加载后才播放；只变换提示本身，不移动作品或改变排版。开始拖图、键盘聚焦、移出视野、窗口改变或切到后台时立即归位，重复滚动不重播；系统减少动态效果时保持静止。
- 每次打开或刷新页面时，先播放 jt 字标出现、消失与双层遮罩退场；即使链接带有作品锚点也会播放，结束后保留原栏目定位。普通站内跳转不重复播放，系统开启减少动态效果时跳过开场。主标题仅在从首屏进入时以位移、压缩和舒展归位；浏览器恢复阅读位置不会提前结束 jt 动画。个人介绍、十二个栏目与能力模块的英文大标题在首次进入视口时揭幕，不反复播放。
- 作品卡片不做逐张错峰揭幕或滚动视差，使用多列静态网格随页面正常展示。PC 鼠标悬停时整张作品卡片平滑放大至 1.04 倍，移开后在 0.32 秒内恢复，图片与文案一起缩放，不裁切画面、不改变网格占位；适用于图片、视频、首页预览及详情长图卡片。仅在宽度大于 700px、支持精细指针与悬停、未启用减少动态效果时生效，移动触屏和 IP 展台保持原样。个人介绍中的信息卡片仍有轻量入场；桌面仅首屏角色视频保留小幅视差。
- IP 展台进入视野后持续匀速环形转动，4 个姿态约 22 秒一圈，没有逐张停留或启动等待。鼠标 / 笔碰到角色图像时原地冻结，离开图像立即接着转；展台空白区域不触发暂停。拖动直接接管当前角度，松手后从原位置恢复（鼠标仍在角色上则保持暂停）。两侧箭头点击以约 0.52 秒转至相邻姿态，也支持方向键。没有独立暂停按钮、IP 大图或滚轮切换。键盘聚焦、离开视野、切到后台时暂停自动运动，系统减少动态效果时只保留手动操作。角色完整显示、浅色背景及独立说明区域不变。
- 方图、竖版、营销主图和展会全部正常排列，没有固定展台、内层滚动或拖动浏览。方图、竖版与营销主图在 PC 和手机上均为三列；展会在 PC 和手机上均为两列。原有标题进场动画保留，图片不做滚动联动。
- 不再提供重复的图库入口，直接点击作品查看大图；关闭后返回原来的滚动位置与焦点。图片不裁切，也不在悬停时放大裁掉边缘文字。已精简重复英文标签与操作说明，辅助阅读提示保留在无障碍描述中。
- 大图与视频预览平滑打开、淡出关闭。关闭视频时立即停播，不等待退场动画结束；Esc、点击遮罩与关闭按钮行为一致。
- 图片查看器顶部约 45px、底部约 44px；移除分类名、「原尺寸」切换按钮、底部计数与翻页按钮，名称使用 13–14px 单行省略。放大镜滑块从适应尺寸的 50% 缩放至每张图片的原始尺寸，最右端显示「原尺寸」，不会超出原始像素大小。默认 100% 为适应窗口（长图为适应宽度），小图不会被自动放大，窗口大小变化时同步更新缩放上限，缩放不改变原图比例。放大后可按住鼠标拖动或用触屏滑动查看各个边角，缩小时重新居中。滑块支持方向键、Home、End，且不会误切换作品；图片无需平移且焦点不在滑块时，左右方向键仍可切换作品，并重置为 100%。首页/详情卡片内拖动和 IP 展台不变。
- 首屏与标题动效使用 GSAP + ScrollTrigger；页面内容默认可见，仅在进场时设置临时动画状态，避免标题因未触发而一直隐藏。遵循系统“减少动态效果”设置，动画结束释放临时样式，卸载时清理监听和动画。首屏与页尾角色的眼睛跟随逻辑保持原样。
